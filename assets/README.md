# Logo assets

The README uses the Python palette and MCP overlay from the libtmux asset kit.
`logo.svg` is the vector mark; `logo.png` is the transparent 512px fallback.
The repository social card at `../.github/social-preview.png` uses the cog.

The geometry comes from the project owner’s libtmux and tmuxp SVGs. The palette
uses [GitHub Linguist’s Python color](https://github.com/github-linguist/linguist/blob/538da05f034fa5c83bd81df128d144e208898da3/lib/linguist/languages.yml).
The overlay uses the symbol from the [MCP logo](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/088176704a4e8f20e7f1d237de1de8484aa412fd/docs/logo/light.svg).
